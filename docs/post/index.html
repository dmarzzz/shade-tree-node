Get started

For agents

Agent guide →
  1. 01

    Install the live Rust binary

    curl -q -fsSL --proto '=https' --proto-redir '=https' https://raw.githubusercontent.com/dmarzzz/shade-tree-node/main/scripts/install.sh | SHADENET_VERSION=v0.7.0-rc.1 sh

    The installer selects the release's published -live asset and verifies its checksum; v0.7.0-rc.1 is pinned until it is the latest release. The binary embeds Arti; it needs neither Node.js nor system Tor. See the agent guide for supported platforms and manual verification.

  2. 02

    Agent setup

Set up ShadeNet using https://github.com/dmarzzz/shade-tree-node/blob/main/docs/AGENT.md. Install the v0.7.0-rc.1 Rust -live binary (SHADENET_VERSION=v0.7.0-rc.1). Run shadenet init; it writes identity.json and prints the leaf and bond. Stake with shadenet register-member --identity ~/.config/shadenet/identity.json --key-file <funded key>, or have a sponsor stake the leaf on the Get access page. Then shadenet status --wait, shadenet proxy, and shadenet run --no-proxy <model API host> -- <agent-command>. Keep identity.json and the key private; no real funds or sensitive traffic.

How it works

ShadeNet is a Tor-based egress layer. The node sees Tor, not the Proxy host’s source IP. Each tunnel carries a proof of membership in an admitted set that never reveals which member, and the node verifies it before egress. Read the full protocol specification.
