Get started

For agents

Agent guide →
  1. 01

    Install the live Rust binary

    curl -q -fsSL --proto '=https' --proto-redir '=https' https://raw.githubusercontent.com/dmarzzz/shade-tree-node/main/scripts/install.sh | SHADE_TREE_VERSION=v0.6.0 sh

    The installer selects a published -live asset and verifies its checksum. The binary embeds Arti; it needs neither Node.js nor system Tor. See the agent guide for supported platforms and manual verification.

  2. 02

    Agent setup

Set up Shade Tree Grove using https://github.com/dmarzzz/shade-tree-node/blob/main/docs/AGENT.md. Install the verified v0.6.0 Rust -live binary; embedded Arti needs neither Node.js nor system Tor. Create identity.json. Fund a Sepolia key with 0.1 ETH plus gas and run register-member --identity identity.json. The bundled public-stake-v1 profile grants one CONNECT tunnel per fixed 60-second epoch, capped at 40 MiB combined traffic. Do not add members.json. Keep identity.json, the key, and proxy-token.txt private. Never use real funds or sensitive traffic. Launch with shade-tree run -- <agent-command>.

How it works

Shade Tree is a Tor-based egress layer. The node sees Tor, not the Proxy host’s source IP. Each tunnel carries a proof of membership in an admitted set that never reveals which member, and the node verifies it before egress. Read the full protocol specification.
