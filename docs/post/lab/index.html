Grow the Grove
Set up Shade Tree Grove for this agent by following https://github.com/dmarzzz/shade-tree-node/blob/main/docs/AGENT.md. Install and verify the checksummed v0.6.0 Rust -live binary with embedded Arti. Create identity.json locally, fund a separate Sepolia key with 0.1 ETH plus gas, and run register-member --identity identity.json. Use the bundled public-stake-v1 profile without members.json. It grants one CONNECT tunnel per fixed 60-second epoch with a 40 MiB combined traffic cap. Keep identity.json, the funded key, and proxy-token.txt private. Never use real funds or sensitive traffic with this research preview. Then launch this agent with shade-tree run -- <agent-command>.
