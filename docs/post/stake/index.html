Step 1: set up with the CLI

Run these on the machine where your agent runs.

Install the client

curl -fsSL --proto '=https' --proto-redir '=https' \
  https://raw.githubusercontent.com/dmarzzz/shade-tree-node/main/scripts/install.sh \
  | SHADENET_VERSION=v0.7.4 sh

Create the identity

shadenet init

shadenet init prints it. The identity commitment is public. The secret stays in identity.json on that machine, and this page never asks for it. To stake for someone else, paste theirs.

Step 2: stake the bond

identity commitment
None yet. Enter it in step 1.
bond
0.01 Sepolia ETH, returned 24 hours after you leave. It buys 8 sessions per minute.
wallet

Staking links your wallet to this membership on chain, permanently. To keep a wallet you care about out of it, shield ETH with Railgun, send it to a fresh wallet, and stake from that one. An agent can do the same through agent-boost.

ShadeNet is a research preview on Sepolia. The code is unaudited, the proof keys come from a trusted setup, and it should not be considered secure against a motivated actor: do not use it for real funds or sensitive traffic.

Step 3: start

Nodes admit the identity once its stake is final, usually 13 to 16 minutes after it confirms.

Human

  1. shadenet status --wait

    Returns once the stake is final and nodes admit the identity.

  2. shadenet proxy

    Starts the local proxy. Leave it running.

  3. shadenet run --no-proxy api.openai.com -- your-agent

    Runs your agent with its web traffic on ShadeNet. Keep your model API host on --no-proxy.

Agent

Set up ShadeNet using https://github.com/dmarzzz/shade-tree-node/blob/main/docs/AGENT.md. Install the v0.7.4 Rust -live binary (SHADENET_VERSION=v0.7.4). Run shadenet init; it writes identity.json and prints the identity commitment and bond. Stake with shadenet register-member --identity ~/.config/shadenet/identity.json --key-file <funded key>, or have a sponsor stake the identity commitment on the Get access page. Then shadenet status --wait, shadenet proxy, and shadenet run --no-proxy <model API host> -- <agent-command>. Keep identity.json and the key private; no real funds or sensitive traffic.

shadenet mcp

Serves shadenet_fetch and shadenet_status to any MCP client over stdio. In Claude Code: claude mcp add shadenet -- shadenet mcp.

Leave and details

Leave

Leave from the machine that holds identity.json. The key only pays gas.

shadenet exit-member --identity ~/.config/shadenet/identity.json --key-file gas.key

The bond unlocks 24 hours later. Withdraw it to a fresh address, so the refund does not point back at the funder.

shadenet withdraw-member --identity ~/.config/shadenet/identity.json --recipient 0xFRESH --key-file gas.key
The bond

The bond is refundable collateral. Tier 8 buys 8 sessions per minute, up to 6 connections and 40 MiB each. Sending two different requests from the same slot in one minute reveals the secret and lets anyone slash the bond. A valid slash pays 1/10 of the bond to whoever reports it and burns the rest.

Exit and withdraw need identity.json. Nobody can recover it for you: lose it and the bond stays locked for good.

The contract is 0x7899…680b on Sepolia. It, the bond and the unbonding time can change at the next deployment. Protocol parameters

No Sepolia ETH

Faucet drips are often smaller than the bond, so funding can take a few tries. Someone else can also stake for you: copy the link in step 2 and send it to them. They never see the secret.
